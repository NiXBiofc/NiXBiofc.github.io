Privacy Policy

Last updated: 11 October 2026

1. About this website

This is a static project website hosted by GitHub Pages. It does not provide website accounts, payment processing, or contact forms. GitHub may process technical request information such as IP addresses for hosting, security, and abuse prevention under its own policies.

2. NIXBI Launcher and Google data

NIXBI Launcher is a separate Windows application. If you choose to connect Google, the application displays Google's consent screen and requests the permission shown there. The current integration requests the gmail.readonly scope; this scope is broader than viewing labels and can allow access to Gmail data covered by that permission. Review the actual consent screen before proceeding.

The intended desktop architecture communicates with Google APIs from the user's device. OAuth tokens are intended to be stored locally on Windows and protected using Windows Data Protection API (DPAPI). NiXBi does not intend to operate a backend that receives Gmail message contents. This statement must be kept aligned with the code in the released build.

Google data is used to provide the Gmail feature the user chooses to enable. It is not intended to be sold, used for advertising, or shared except as required to provide the feature, comply with law, or at the user's direction. The application is intended to follow the Google API Services User Data Policy, including Limited Use requirements.

3. Local account information

OAuth credentials and account tokens are separate from this public website. Never upload them to this repository, attach them to issue reports, or include them in a public launcher ZIP. Disconnect accounts through the application's account controls and/or revoke access from Google Account security settings. Removing local files alone may not revoke Google authorization.

4. Gifts Pokup Bot

Gifts Pokup Bot is a separate Telegram project. This website does not handle its orders or payments. Telegram and the bot's operators may process the information users provide in Telegram. Review the bot's in-app guidance and contact the project through the bot for questions about its data handling.

5. Third-party services and changes

Links can lead to GitHub, Google, Telegram, or other services governed by their own terms. This policy may change as the projects evolve; the date above indicates the latest revision.

For general project questions, use the GitHub link in the top navigation.
