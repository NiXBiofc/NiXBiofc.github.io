NIXBI Launcher gallery screenshots

Place your own screenshots in this folder with these exact names:
  screenshot-1.png  (main workspace)
  screenshot-2.png  (Radial Menu)
  screenshot-3.png  (personalization)
  screenshot-4.png  (extensions)

Use PNG screenshots. The website gallery will automatically show the images when these files are uploaded to GitHub. If a file is missing, a matching placeholder is displayed. Recommended aspect ratio: 16:9.
