Privacy Policy

Last updated: 11 October 2026

1. Who develops NIXBI Launcher

NIXBI Launcher is an independent Windows desktop project maintained under the GitHub profile NiXBiofc. It is not made by, affiliated with, or endorsed by Google.

2. Information the launcher processes

The core launcher stores the user's local configuration, such as selected applications, paths, appearance choices, and extension settings, on the user's device.

If the user chooses to connect Gmail, the launcher uses Google's OAuth flow to obtain permission for the requested Gmail API scope. The current build requests https://www.googleapis.com/auth/gmail.readonly. This is a broad read-only permission; Google may treat it as a restricted scope during verification.

The Gmail integration uses the API to retrieve label/folder metadata for the menu and open the selected label in Gmail. It does not intentionally send email, change message contents, or upload mailbox data to the developer. The OAuth scope is broader than the menu’s primary label-browsing purpose; users should review the Google consent screen and grant access only if comfortable with the requested permission.

3. Where data is stored and shared

The intended desktop-only design stores OAuth credentials on the user's Windows profile and protects locally stored token data using Windows DPAPI. The project does not intend to operate a developer-hosted backend that receives Gmail messages or OAuth refresh tokens.

Google processes sign-in and API requests under Google's own terms and privacy policy. NIXBI does not sell Google user data or use it for advertising. No Google user data should be shared with third parties except as necessary for the user-requested Google authentication/API flow or where required by law.

4. User control and deletion

Users can disconnect a Google account from the launcher, revoke the application's access in their Google Account security settings, or remove the local NIXBI account data from their Windows profile. A release should provide a clear in-app disconnect/removal path; the exact local storage path should be documented in the release's help text.

To revoke access at Google, visit Google Account connections and remove NIXBI Launcher.

5. Data retention

Local launcher settings and encrypted authentication data remain on the user's device until the user disconnects the account, removes the stored data, or uninstalls/removes the relevant local profile data. Google may retain records according to Google's own policies.

6. Security

The project is designed to use the system browser for OAuth and to store tokens locally rather than embed user tokens in the application package. Users should only download launcher builds from the project maintainer's official distribution channels and should keep Windows and the launcher updated.

7. Children's privacy

NIXBI Launcher is a general-purpose desktop utility and is not designed to collect personal information from children through a developer-operated service. The launcher does not intentionally collect information on a developer server.

8. Changes to this policy

This page may be updated when the launcher changes. The date at the top will be updated when material changes are made. Users should review this page before authorizing new Google permissions.

9. Contact

For questions about this policy, contact the project maintainer through the NiXBiofc GitHub profile. Add a monitored support email to the Google Cloud OAuth branding settings before submitting for verification.

Google API Services User Data Policy: the use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
