Privacy Policy

Last updated: 11 October 2026

1. About this site

This website introduces independent projects associated with NiXBiofc. The pages are static and do not provide user registration, payment processing, or website forms. The site is hosted by GitHub Pages; GitHub may process technical information such as IP addresses and request data for hosting, security, and abuse prevention under its own policies.

2. NIXBI Launcher and Google data

NIXBI Launcher is a separate Windows application. If you choose to connect a Google account, the application may request the Gmail API permission shown on Google’s consent screen. The current implementation requests gmail.readonly; this is broader than simply opening labels and allows access to Gmail data covered by that scope. Do not connect an account unless you understand and accept the requested permission.

In the intended desktop architecture, the application communicates with Google APIs from the user's device. OAuth token data is stored locally on Windows and protected using Windows Data Protection API (DPAPI). NiXBi does not intend to operate a backend that receives Gmail message contents. This description must be kept aligned with each released build; consult the release documentation and Google consent screen for the actual permissions in use.

Google data accessed by NIXBI Launcher is used only to provide the feature you enable, such as displaying Gmail labels and opening the relevant Gmail view. It is not intended to be sold, used for advertising, or shared with third parties except as required to provide the feature, comply with law, or at the user's direction. The app's use of Google data is intended to follow the Google API Services User Data Policy, including the Limited Use requirements.

3. Local account data

Google credentials and account tokens are distinct from the public website. They should never be uploaded to this repository, attached to issue reports, or included in a shared launcher ZIP. To disconnect an account, use the app's account controls and/or revoke the app's access from your Google Account security settings. Removing local application files may not revoke an authorization previously granted to Google.

4. Gifts Pokup Bot

Gifts Pokup Bot is a separate Telegram project. This website does not handle its orders or payments. When you interact with the bot, Telegram and the bot's operators may process the information you provide in Telegram. Review the bot's in-app instructions before use; contact the project through the bot for questions about its processing practices.

5. External services and changes

Links may lead to GitHub, Google, Telegram, or other third-party services governed by their own privacy terms. This policy may be updated as projects evolve. The date above indicates the latest revision of this page.

For questions about the site or projects, contact the project maintainer through the NiXBiofc GitHub profile.
